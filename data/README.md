# Данные

Описание данных (data card): источники, условия использования, состав и известные проблемы.

Снимок подготовки корпуса от **18 ноября 2026 года**.

Таблица для работы команды: [substances_catalog.xlsx](substances_catalog.xlsx). В ней два листа:
план на 100 веществ и реестр выбранных SDS. Excel и CSV отражают один снимок данных;
после пополнения корпуса их нужно обновлять вместе.

- `substance_candidates.csv`: план на **100 уникальных веществ / CAS**. Названия и CAS сверены
  с PubChem. Очередь 1 — 20 веществ для MVP, очередь 2 — 46 для расширения, очередь 3 — 34 дополнительных.
- `substances.csv`: реестр **19 скачанных SDS для 17 веществ**, 316 страниц. Одна строка — один продукт,
  регион и версия документа. Все эти PDF находятся в `raw/sds/`.
- `reference/pubchem_identity_snapshot.json`: сохранённые ответы PubChem для всех 100 CAS,
  адреса запросов и дата проверки. Это справочник идентичности, не база GHS-классификации.

Список кандидатов и реестр SDS имеют разные назначения. Кандидат без выбранного SDS не является
документом корпуса. `suggested_forms` содержит планируемые варианты, а `concentration` в реестре —
формулировку из заголовка конкретного SDS. Группа в списке кандидатов служит для отбора и не является
классом хранения TRGS 510. Очерёдность — рабочий выбор команды, а не оценка опасности.

## Форматы

**`substance_candidates.csv`** — одна строка на уникальный CAS:

| Поле | Смысл |
|---|---|
| `substance_id` | стабильный идентификатор S001…S100 |
| `name_ru`, `name_en` | названия для работы команды и поиска SDS |
| `cas` | CAS выбранной химической формы; гидраты и безводные формы различаются |
| `group` | группа для подбора корпуса, не класс хранения |
| `priority` | 1 — MVP, 2 — расширение, 3 — дополнительные случаи |
| `suggested_forms` | предлагаемые концентрации, формы или особенности продукта; ещё не подтверждённые характеристики поставки |
| `pubchem_cid`, `pubchem_title` | CID и название, возвращённые PubChem по CAS |
| `identity_source_url`, `identity_checked_at` | ссылка на PubChem и дата проверки |
| `selected_sds_count` | число документов в текущем `substances.csv`; пересчитать после пополнения корпуса |
| `next_action` | `select_sds` — подобрать документ; `annotate_sds` — разметить уже выбранный SDS |

**`substances.csv`** — одна строка на один скачанный SDS. Первые восемь колонок исходного формата
сохранены, новые поля добавлены справа:

| Поле | Пример | Комментарий |
|---|---|---|
| `substance` | Nitric acid 65 %, pure | полное название продукта из SDS |
| `cas` | 7697-37-2 | |
| `concentration` | 65 % | концентрация или чистота буквально из заголовка SDS; `12 % Cl` означает активный хлор, не массовую долю NaOCl |
| `vendor` | roth | код поставщика |
| `lang` | en | en, de, ru |
| `doc_id` | roth_x898_de_en_20250805_v1_1 | поставщик, артикул, регион, язык, дата редакции (или составления), версия; имя PDF без расширения |
| `source_url` | | откуда скачан |
| `downloaded_at` | 2026-11-18 | дата фактической загрузки |
| `product_id` | X898 | артикул из раздела 1 SDS; строка, начальные нули значимы |
| `sds_version` | 1.1 | версия из PDF, включая префикс GHS при его наличии |
| `sds_revision_date` | 2025-08-05 | дата редакции; пусто, если в документе её нет |
| `sds_compilation_date` | 2025-03-10 | дата составления; хранится отдельно от редакции |
| `sds_jurisdiction` | DE | страна редакции SDS: AU, CH, DE, GB, IE или MT |
| `pdf_sha256`, `pdf_pages` | | контрольная сумма исходного файла и число страниц |
| `substance_id` | S009 | связь со списком кандидатов |

Для растворов `cas` относится к обозначенному основному веществу. Это не полный состав смеси и не
достаточный ключ выбора продукта. При выборе документа учитывайте артикул, концентрацию, регион и версию.
Новую редакцию сохраняйте отдельным документом, не заменяйте файл с прежним `doc_id`.

**`reference/trgs510_compatibility.csv`** — одна строка на пару классов хранения (порядок в паре не важен):

| Поле | Пример | Комментарий |
|---|---|---|
| `class_a`, `class_b` | 3, 5.1B | классы хранения TRGS 510 |
| `verdict` | separate | allowed, restricted или separate |
| `source` | TRGS 510, … | пункт или таблица документа |
| `note` | | условия для restricted |

Пары, которых нет в таблице, инструмент `check_compatibility` считает `insufficient_data`.

## Состав

План: 100 веществ, включая растворители, кислоты, основания, неорганические и органические соли,
соли металлов и другие лабораторные вещества. Он охватывает разные гидраты, изомеры и формы продукта.

Корпус SDS из `substances.csv`: 19 документов, один поставщик (Carl Roth), один язык (EN), шесть регионов SDS.
Изопропанол представлен продуктами 70 % и ≥99,5 %, соляная кислота — 37 % и 1 mol/l.
Для остальных веществ пока выбран не более чем один документ.
Отдельно в `raw/sds/ILO/` находятся карточки ICSC, добавленные командой; они не входят в этот реестр SDS.

Для всех 19 PDF проверены открытие файла, наличие текстового слоя, CAS и артикула на первой странице,
название продукта, версия, даты, число страниц и SHA-256. Проверка границ всех 16 разделов, извлечения
таблиц, H-кодов и качества цитирования ещё не проводилась. Все страницы содержат извлекаемый текст;
OCR при подготовке реестра не использовался.

Следующее пополнение: SDS для остальных кандидатов, второй и третий поставщики, дополнительные
концентрации и языки. В первую очередь нужны рабочие ссылки на этанол, н-гексан и перманганат калия:
проверенные поисковые ссылки на выбранные продукты возвращали 404, поэтому эти документы в корпус не включены.

## Известные проблемы

- Публичные ссылки поставщика могут устаревать. Для воспроизводимости используйте сохранённый PDF и его SHA-256.
- Региональные версии одного поставщика отличаются. Их классификации и условия нельзя автоматически объединять.
- Команда добавила таблицу совместимости TRGS 510 и исходные PDF. Проверка корректности её правил
  и исключений не входила в подготовку каталога веществ.
- Список кандидатов не содержит выводов о совместимости, H-кодов или рекомендаций по СИЗ.
- Парсер и сборщики в `scripts/` пока остаются заготовками. Подготовка этой таблицы их не реализует.
