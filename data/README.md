# Данные

Описание данных (data card): источники, условия использования, состав и известные проблемы.

## Источники

| Источник | Что берём | Как получено | Дата | Условия использования | Объём |
|---|---|---|---|---|---|
| Сайты производителей (Sigma-Aldrich, Fisher, Carl Roth, Merck) | SDS в PDF | скачивание, `scripts/download_sds.py` или вручную | | | |
| PubChem PUG REST / PUG View | GHS-классификация: H-коды, пиктограммы, сигнальное слово | `scripts/build_ghs_db.py` | | | |
| TRGS 510 | таблица совместного хранения по классам хранения | вручную из официального текста | | | |
| ILO | Карточки с описанием веществ | scripts/fetch_icsc_cards.py | | | |

## Структура

| Путь | Что лежит | В git |
|---|---|---|
| `substances.csv` | список веществ и SDS | да |
| `raw/sds/` | исходные PDF, `<doc_id>.pdf` | да |
| `reference/trgs510_compatibility.csv` | правила совместного хранения | да |
| `processed/chunks.jsonl` | чанки с метаданными (`chemsafety.schemas.Chunk`) | нет, собирается `scripts/build_index.py` |
| `processed/ghs.sqlite` | база для `get_ghs` | нет, собирается `scripts/build_ghs_db.py` |
| `processed/storage_log.sqlite` | журнал хранения для демо | нет |

## Форматы

**`substances.csv`** — одна строка на один SDS:

| Поле | Пример | Комментарий |
|---|---|---|
| `substance` | Nitric acid | название из SDS |
| `cas` | 7697-37-2 | |
| `concentration` | 65 % | пусто, если чистое вещество |
| `vendor` | sigma | |
| `lang` | en | en, de, ru |
| `doc_id` | sigma_7697-37-2_65_en | `<vendor>_<cas>_<концентрация>_<язык>`, имя PDF без расширения |
| `source_url` | | откуда скачан |
| `downloaded_at` | 2026-10-28 | |

**`reference/trgs510_compatibility.csv`** — одна строка на пару классов хранения (порядок в паре не важен):

| Поле | Пример | Комментарий |
|---|---|---|
| `class_a`, `class_b` | 3, 5.1B | классы хранения TRGS 510 |
| `verdict` | separate | allowed, restricted или separate |
| `source` | TRGS 510, … | пункт или таблица документа |
| `note` | | условия для restricted |

Пары, которых нет в таблице, инструмент `check_compatibility` считает `insufficient_data`.

## Состав

Заполнить после сбора: число веществ, документов, производителей и языков; сколько сканов;
сколько веществ представлено в нескольких концентрациях.

## Известные проблемы

Заполнить: документы с битым текстовым слоем, нестандартной нумерацией разделов, таблицами на несколько страниц.
