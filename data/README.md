# Данные

## Основная таблица веществ

`processed/substances.csv` — результат разбора локальных HTML-карточек из `raw/sds/ILO/`.
Текущий корпус: 1691 карточка, 50 колонок. Одна строка соответствует одному документу.
Старая таблица продуктов Carl Roth заменена этой выгрузкой; её 19 PDF удалены.

Запуск из корня проекта:

```powershell
python scripts/parse_ilo_cards.py
python scripts/view_ilo_cards.py
```

Первая команда формирует единственный CSV `data/processed/substances.csv`. Вторая обновляет
локальный HTML-просмотр `data/processed/ilo_cards.html` с поиском, сортировкой
и полными карточками. После пересборки обновите открытую страницу браузера.

Заголовки CSV английские, текст сохраняется на языке источника (в текущем корпусе `ru`).
Перевод, дополнение химических сведений и пересчёт единиц не выполняются.
Отсутствующие значения пустые. Формат — UTF-8 с BOM, разделитель — запятая;
переносы строк внутри ячеек заключены в кавычки CSV.

Все 50 колонок и их порядок определены в `FIELDNAMES` файла `scripts/parse_ilo_cards.py`.
Они включают идентификаторы, опасности, профилактику, первую помощь, хранение,
классификацию, физико-химические свойства, воздействие, экологию и примечания.

- `source` — путь исходного HTML относительно `data/raw/sds/ILO/`.
- `lang` — язык карточки; язык обёртки HTML не используется вместо языка содержания.
- `doc_id` — `ilo_icsc_<номер>_<язык>[_v<версия>]`.
- `vapour_pressure` и `solubility_in_water` сохраняют полную строку свойства,
  включая реальные единицы и температуру измерения.
- `transportation` содержит транспортный блок, `un_classification` — его подраздел ООН.

При ошибке структуры карточки или повторном `doc_id` экспорт завершается с ошибкой,
не заменяя предыдущий CSV. Для проверки парсера:

```powershell
python -m pytest tests/test_parse_ilo_cards.py
```

## Остальные файлы

| Путь | Назначение |
|---|---|
| `raw/sds/ILO/` | Исходные HTML-карточки ILO/ICSC |
| `raw/trgs_510.pdf`, `raw/TRGS-510_EN_2014-11.pdf` | Документы TRGS 510 для правил хранения |
| `reference/trgs510_compatibility.csv` | Таблица совместного хранения |
| `substance_candidates.csv`, `substances_catalog.xlsx` | Предыдущий план и каталог; не отражают текущую таблицу ILO |
| `reference/pubchem_identity_snapshot.json` | Ранее сохранённые ответы PubChem для списка кандидатов |

Старые поля `selected_sds_count` в списке кандидатов и реестр SDS в Excel относятся
к предыдущему корпусу, PDF которого удалены. Для текущих данных используйте `processed/substances.csv`.
Документы TRGS 510 сохранены; корректность правил совместимости здесь не проверялась.
Заготовки скачивания PDF и построения индекса пока не интегрированы с новой схемой ILO.

Исходные карточки получены из ILO/ICSC; загрузчик находится в
`src/chemsafety/parsing/fetch_icsc_cards.py`. Права на исходные материалы определяются
их правообладателями; лицензия проекта не заменяет условия источников.
