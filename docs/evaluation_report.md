## Результаты

Таблица из `reports/final/summary.md`: baseline, v1, v2 по качеству, задержке и стоимости.
Для основных метрик укажите 95%-доверительные интервалы (bootstrap), для сравнения версий — тест МакНемара.

## Поиск отдельно от ответа

Recall@k и MRR по системам; разбор вопросов, где правильный раздел не попал в выдачу.

## Проверка LLM-судьи

Сколько ответов размечено вручную, согласие и Cohen's κ между судьёй и людьми, типичные расхождения.
